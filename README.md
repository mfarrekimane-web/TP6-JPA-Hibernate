# TP6 : JPA / Hibernate

## Description
Application de gestion commerciale utilisant JPA et Hibernate avec MySQL : entités Categorie et Produit, relation ManyToOne/OneToMany, Named Queries, Criteria API, pagination et tests JUnit.

## Structure du dépôt
- [gestion-commerciale](./gestion-commerciale) : code source
- [CAPTURE](./CAPTURE) : captures d'écran de l'exécution

## Exécution
Démarrer MySQL (base `gestion_commerciale`), puis lancer `Main` ou `ProduitDaoTest` depuis IntelliJ.
